# Temperature Converter

A lightweight temperature converter built with HTML, CSS, and vanilla JavaScript. Enter a temperature, choose a conversion, and the result is displayed to one decimal place.

## Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Convert Celsius to Kelvin
- Responsive, dark-themed interface
- Input and conversion-selection feedback

## Getting started

No dependencies or build tools are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter a temperature, select a conversion, and click **Check!**

## Conversion formulas

- Celsius to Fahrenheit: `(°C × 9 / 5) + 32`
- Fahrenheit to Celsius: `(°F − 32) × 5 / 9`
- Celsius to Kelvin: `°C + 273.15`
